# 枚举
- 相当于定义一种数据类型，只能是某些值
- enum（enumerate）
- 现代C++中更推荐枚举类enum class，而不是枚举enum，枚举类后面再介绍
```cpp
// 枚举元素默认为int，但前面也说过，不同数据类型的本质区别其实只有内存空间大小
// : unsigned char 相当于规定枚举元素的类型，char只占1字节，可以节省空间
enum Example : unsinged char {
	A, B, C         //默认A=0, B=1, C=2
};

int main() {
    Example e = A;
    if (e == A) {
        std::cout << "A" << std::endl;
    } else if (e == B) {
        std::cout << "B" << std::endl;
    } else if (e == C) {
        std::cout << "C" << std::endl;
    }
}
```
# 构造函数
- 构造函数不写返回类型
- 初始化变量
	- 在java中所有变量都会初始化为0
	- 在C++中所有变量都要通过构造函数初始化，否则是随机的值
- 构造函数的签名不同时，可以有多个构造函数（重载）
- 特殊构造函数（相对复杂）
	- 复制构造函数
	- 移动构造函数
- 禁用构造函数：
	- 例：有静态方法，想仅用`Log::Write()`调用，而不是创建实例后调用，就可以禁用构造函数，两种方法：delete或放入private里
↓ 这段代码就是静态方法的两种调用
```cpp
class Log {
public:
    static void Write() {
        std::cout << "Log::Write()" << std::endl;
    }
};
int main() {
    Log::Write();
    
    Log entity;
    entity.Write();
}
```
↓ 要想禁用构造函数可以这么写，Log entity时就报错了。
方法一：
```cpp
class Log {
private:
	Log() {}
public:
    static void Write() {
        std::cout << "Log::Write()" << std::endl;
    }
};
```
方法二：
```cpp
class Log {
public:
	Log() = delete;
    static void Write() {
        std::cout << "Log::Write()" << std::endl;
    }
};
```
# 析构函数
- 如果一个类没有写析构函数，系统会给一个默认的
- 析构函数的内容通常是删除变量、清理使用过的内存
- 析构函数会在销毁对象时运行（很少手动调用），两种情形：
	- 堆分配对象，new出来的，delete时会调用析构函数
	- 栈分配对象，直接定义的，出作用域时会调用析构函数
		- 所以对于栈分配对象，直接写在main函数里会到程序结束才释放，更好的做法是封装到函数里，出这个函数时就会被释放了
- 析构函数的写法：类同名并在前面加个`~`
