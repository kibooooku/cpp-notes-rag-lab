# 变量
- C++里的基本变量类型挺灵活的，可以干不属于它们类型的事情，所以可以说：
	- 区分不同变量类型的根本是它们的占用空间大小（字节）
- 某类型分配多少内存具体取决于编译器。
- 常用整型：
	char 1
	short 2
	int 4 （-21亿~21亿，因为32字节，1个符号位，2^31≈21亿）
	long 4
	long long 8
- unsigned关键字加在前面，表示无符号数
# 头文件
- 头文件可能有嵌套include链条，所以某程序里可能被include了多次同一个同文件，就可能导致编译错误，因此需要加`#pragma once`（这是新语法糖）或：
```
#ifndef XXX  // if not define
#define XXX
......
#endif

//这种写法和#pragma once等价
```
- `#include`时会用< >或者“ ”
	- “ ”内其实是填路径，只是如果所有cpp同级就不需要加路径了
	- iostream当然也能用" "包，只是< >不能使用于自定义的文件
	- iostream就是没有扩展名的文件（C++标准库都这样），而带.h的库一般是C标准库
# 调试
- 断点+读取内存（F9或点侧边栏，打在可执行语句处）
	- release mode和debug mode
		- 在debug模式下会执行所有语句，调试时使用这个模式
		- 在release模式下会有自动的优化，调试时打断点的语句可能就不执行了
	- F10 11 12：step in进入函数，step over下一句，step out出函数
	- 指着的语句是即将执行的（还没执行）
	- autos locals窗口会自动显示一些变量，watch窗口可自行输入变量名来观察变量
	- F5 continue，继续运行，直到下一个断点
	- 转汇编调试（记得关掉各种优化，否则很多语句会被优化掉）
# 条件、循环
- 条件分支语句其实会降低代码速度，用数学运算代替其实是效率更高的代码
```C++
else if
其实就是
else
{
	if
}
```
