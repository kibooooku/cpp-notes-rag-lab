# 指针
- 指针是表示内存地址的整数，对所有类型指针都是如此
- 指针在64位机里占8字节，32位机里占4字节
- 空指针定义：
```C++
void* ptr = 0;
void* ptr = NULL;
void* ptr = nullptr;
```

```C++
char* buffer = new char[8];
memset(buffer, 0, 8);
delete[] buffer;
```
- char类型占一个字节，分配8个连续字节，首地址返回给指针buffer
- 上面这三行代码的潜在问题：
	1. **异常安全问题**：如果在 `new` 和 `delete` 之间抛出异常，`delete[]` 不会被执行，导致内存泄漏。
	2. **悬空指针风险**：`delete[]` 后，`buffer` 变量仍然保存着原来的地址，如果程序员误用会导致**未定义行为**（程序崩溃或数据损坏）。
	3. **需要手动管理**：你必须时刻记得调用 `delete[]`，维护成本高。
- 现代C++推荐写法：
	- **固定大小数组**（8 个 char）：直接用栈数组 `char buffer[8] = {};`，自动初始化为 0，无需手动释放。
    - **需要动态大小且要清空**：使用 `std::vector<char> buffer(8, 0);`，内存自动管理，自带清零，安全且高效。
    - **如果确实需要原始指针操作**：使用智能指针 `std::unique_ptr<char[]> buffer = std::make_unique<char[]>(8);` 并手动 `std::fill(buffer.get(), buffer.get() + 8, 0);`，自动释放，无需 `delete`。
# 引用
- 引用是指针的扩展，是指针的语法糖
- 引用必须进行“引用”，没有自己的存储空间，只是对其它变量对引用，<span style="color:rgb(255, 192, 0)">相当于别名</span>
	- 所以定义引用变量时必须直接赋值，没法不引用而存在
- <span style="color:rgb(255, 192, 0)">引用变量在绑定对象后不能更改对象，而指针可以</span>
	- 下面这段代码中，试图让ref的引用对象更改为b，但实际上ref是a的别名，所以a的值变为了b的值即10，而ref的引用对象没有改变
```C++
    int a = 5;
    int b = 10;
    int& ref = a;
    ref = b;
```
- 指针可以改变指向的对象，本例中ptr最终指向对象为b的地址
```C++
    int a = 5;
    int b = 10;
    int* ptr = &a;
    ptr = &b;
```

- 例子：函数实现自增
```C++
void increment(int& x) {
    x++;
}
int main() {
    int a = 5;
    increment(a);
}
```
或者【因为引用正是指针的语法糖，引用可以让指针更简洁】
```C++
void increment(int* x) {
    (*x)++;
}
int main() {
    int a = 5;
    int* ptr = &a;
    increment(ptr);
}
```
