# 开发集原始结果

本目录保存两轮 **独立开发集** 的完整公开副本，每轮为 D01–D06 × BM25/向量，共 12 条。没有正式 Q01–Q20 的评分结果。

- `dev-01` 保留初版的两条引文校验错误，未覆盖。
- `dev-02` 是引用协议修正后的整轮复测；提示词/配置指纹不同，单独保存。
- `judgments.csv` 保持未审空白，不以系统状态当人工判分。
- `run_metadata.json` 保存来源、模型、提示词/配置和题库指纹；`warmup.json` 记录冷加载，原始耗时不当正式成绩。

事实、修复和费用上界见 [开发验证记录](../../docs/development-validation.md)。正式实验仍须先审核 [20 题金标准](../review-sheet.md)。
