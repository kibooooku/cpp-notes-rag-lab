## 对现场追问的回答

“本机 embedding 是什么？”——把笔记和问题在我的电脑上编码成数字向量，用于查找相近证据；它不负责生成最终回答。Chroma 保存和检索这些向量，DeepSeek API 负责回答。

“为什么检索到了还拒答？”——相近主题不一定包含答案。例如介绍了 `std::string` 的可写副本，仍没有介绍 SSO 的机制和适用情形。Top-3 是候选证据，需要检查能否支撑所问结论。

“笔记写错了怎么办？”——保留原文，单独登记待核位置。回答标明资料待核，不把引用存在当成技术已经核实；未经确认的结论不作为权威金标准。
